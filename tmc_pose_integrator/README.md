tmc_pose_integrator
=====================

開発関係者
----------------
- 朝原 佳昭
- 安田 貴夫
  
目的
----------------
本ノードは自律制御部の構成要素であり，オドメトリ結果と各自己位置推定結果を統合した自己位置を出力する．
  
背景
----------------
オドメトリでも充分精度は高いが，長距離を移動すると誤差が蓄積するため，本ノードを用いて誤差を補正する必要がある．
  
前提条件
----------------
- オドメトリが取得できていること．   
  オドメトリは，エンコーダカウント値を積算したx, y, θ座標で表現される．  
- オドメトリを取得するまでは動作しない．  
- 所定の時間以上オドメトリが取得できなかった場合は，エラーログを出力し，動作を停止する．  
  ロボット駆動系ノード（例えば経路追従ノード）が，  
  本ノードが出力する自己位置を参照している恐れがあるため．
- 大域的な自己位置推定値が取得できること．  
  例えば，2次元レーザデータ自己位置推定が動作中．  
  ただし，自己位置推定を購読しなくても，オドメトリのみで動作することは可能．
- SI単位系を使用．x,y,θの単位はそれぞれm,m,rad．
  
振る舞い
----------------
- オドメトリ，レーザ自己位置推定結果を入力とし，グローバル座標系に置ける座標(x,y,θ)を出力する．
- オドメトリ，レーザ自己位置推定結果のデータを一度受け取ると初期化を終了し，自己位置統合処理を開始する．
- 周期駆動する．周期はパラメータとしてユーザが設定可能．
- 現状，線形補間で自己位置統合を行う．今後，共分散行列を用いた統合手法に切り替える．
  
インターフェース
----------------
##### 出版するトピック (トピック名 [型] : 説明)
- "global_pose" [geometry_msgs/msg/PoseStamped] : 自己位置統合結果．フロア座標系．
  
#### 購読するトピック (トピック名 [型] : 説明)
- "laser_2d_pose" [geometry_msgs/msg/PoseWithCovarianceStamped] : レーザ自己位置推定の結果．フロア座標系．

#### 発行する tf (<親フレーム> -> <子フレーム> : 説明)
- <global_frame_id> -> <odom_frame_id> : フロア座標系．ロボット相対座標系に対する位置を設定．

#### 利用する tf (<親フレーム> -> <子フレーム> : 説明)
- <odom_tf_name> -> <base_tf_name> : オドメトリを取得する

#### パラメータ (パラメータ名 [型] [単位] : 説明 (default : XX))
- odom_tf_name [string] : オドメトリフレーム名 (default : "odom")
- base_tf_name [string] : 台車フレーム名 (default : "base_footprint")
- convergence_time [double] [s] : 線形補間における収束時間 (必須パラメータ)
- cycle_time [double] [s] : 周期駆動のための周期であり，自己位置統合結果トピックの出版周期 (必須パラメータ)
- tf_cycle_time [double] [s] : tf更新周期（実装制約上、cycle_timeより小さい値で動作することが出来ない）(必須パラメータ)
- inverted_urg [bool] : 地図生成用URGを使うときtrue (default : false)
- stop_translational_vel_threshold [double] [m/s] : 台車が停止しているとみなす並進速度 (default : 0.001)
- stop_rotational_vel_threshold [double] [rad/s] : 台車が停止しているとみなすその場旋回速度 (default : 0.001)

既知の問題
----------------
- パラメータ設定が最適ではない
- 3次元空間に対応したいが，現状2次元のみの実装となっている． 
  
使用例
----------------

    $ ros2 launch tmc_pose_integrator pose_integrator.launch.py
