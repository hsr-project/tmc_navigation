目的
----------------
本ノードは自律制御部の構成要素であり，オドメトリ結果と各自己位置推定結果を統合した自己位置を出力する．
  
背景
----------------
オドメトリでも充分精度は高いが，長距離を移動すると誤差が蓄積するため，本ノードを用いて誤差を補正する必要がある．
  
前提条件
----------------
- 本ノードが出力する最終的な推定結果のオドメトリが取得できていること．  
  例えば，オドメトリを扱うノードが動作している．  
  オドメトリは，エンコーダカウント値を積算したx, y, θ座標で表現される．  
- オドメトリを取得するまでは動作しない．  
- 所定の時間以上オドメトリが取得できなかった場合は，エラーログを出力し，動作を停止する．  
  ロボット駆動系ノード（例えば経路追従ノード）が，  
  本ノードが出力する自己位置を参照している恐れがあるため安全策として．
- 自己位置推定値が取得できること．  
  例えば，2次元レーザデータ自己位置推定が動作中．  
  ただし，自己位置推定を購読しなくても，オドメトリのみで動作することは可能．
- SI単位系を使用．x,y,θの単位はそれぞれm,m,rad．
- 現状，自己位置推定の入力はレーザ自己位置推定結果のみだが，  
  複数の自己位置推定手法を統合する目的で実装されている．
  
振る舞い
----------------
- オドメトリ，レーザ自己位置推定結果を入力とし，グローバル座標系に置ける座標(x,y,θ)を出力する．
- オドメトリ，レーザ自己位置推定結果のデータを一度受け取ると初期化を終了し，自己位置統合処理を開始する．
- 周期駆動する．周期はパラメータとしてユーザが設定可能．
- 現状，線形補間で自己位置統合を行う．今後，共分散行列を用いた統合手法に切り替える．
- 初期位置は(x, y, θ)=(0, 0, 0)である．初期位置を設定するためのインターフェースは持たない．  
  各自己位置推定が初期位置を与える役割をなす．
  
インターフェース
----------------
- 出版するトピック
    - **/global\_pose**  
      : [geometry\_msgs/PoseStamped]    
        自己位置統合結果．フロア座標系．
  
- 購読するトピック
    - **/laser\_2d\_pose**  
      : [geometry\_msgs/PoseWithCovarianceStamped]  
        レーザ自己位置推定の結果．フロア座標系．

- パラメータ（グローバル）
    - **robot\_base\_tf\_name**  
      : ロボット上腕部のロボット相対座標tf名称．ロボット上腕部に依存する  
    - **robot\_base\_tf\_yaw**  
      : ロボット上腕部のロボット相対座標の姿勢：deg  

- パラメータ（ローカル）
    - **odom\_tf\_name**
      : オドメトリフレーム名
    - **base\_tf\_name**
      : 台車フレーム名
    - **convergence\_time**  
      : 線形補間における収束時間 : sec  
    - **cycle\_time**  
      : 周期駆動のための周期であり，自己位置統合結果トピックの出版周期 : sec  
    - **tf\_cycle\_time**  
      : tf更新周期（実装制約上、cycle_timeより小さい値で動作することが出来ない）: sec  
    - **test\_count**  
      : ランダムテスト実施数 : 回  

- 購読するtf
    - (odom_tf_name -> base_tf_name)のtfを利用してオドメトリを取得する
    
- 発行するtfのフレーム  
    - **(フロア座標系名)**  
      フロア座標系．ロボット相対座標系に対する位置を設定．
